# orca-focus · 虎鲸笔记「专注计时」

从**任意块**发起专注计时：右键块左侧的小点 →「插件命令」→「开始专注」。计时器集中在一个专用的侧边面板里管理；开始/暂停/恢复/结束都会写一条记录到今天的日记（默认直接追加到日记末尾；也可以在设置里指定写进某个日志块），并打上 `#专注日志` 标签（记录开始/结束时间，专注的目标块放在标签的「目标」属性里）。暂停和恢复时也会各弹出一个可选的日志窗，确认才执行、取消则不执行。

不修改块内容、不要求预先打标签，全部走 Orca 官方插件 API。

## 功能

### 从任意块发起专注

- 块左侧小点右键 →「插件命令」→「开始专注…」（Orca 把所有插件命令统一收在这个子菜单里）；
- 开始时必定写一条记录；弹窗里可以顺手填「这次要做什么」，填的内容就是记录正文（留空则正文自动放目标块的引用，见下面的记录格式）；
- 同一时间允许多个计时器并行；
- 暂停时弹出「暂停专注」窗：**点确认才暂停**并写一条日志——填了内容就写成「HH:mm 内容」，留空则写「HH:mm 暂停专注：」+ 目标引用；按 Esc、点遮罩或「取消」则继续计时，不写记录；
- 恢复时同样弹出「恢复专注」窗：**点确认才继续**并写一条日志——填了内容写成「HH:mm 内容」，留空写「HH:mm 恢复专注：」+ 目标引用；取消则保持暂停，不写记录；
- 正在专注的块前面会显示一个**闪烁的小时钟**（纯渲染层标记，不写入笔记；该块的镜像块也会显示）；
- 计时中的块下面会自动插入一个**「专注操作」子块**（真实的子块，保留正常的块小点）：显示实时用时 + 📝 插入备注 / ⏸ 暂停（已暂停时变 ▶ 继续）/ ⏹ 结束；结束或丢弃后自动删除，撤销结束会重新插回来；
- 这个操作块**绑定在源块下面**：拖不走、删不掉（会提示），被其它操作带跑后 3 秒内自动拉回源块第一个子块；复制/粘贴出来的副本会显示为「已停用」，不会控制计时器；
- 操作块是笔记里的真实块，会随笔记同步、可折叠/可撤销；导出时 converter 输出为空，不会污染文本。

### 计时面板（自定义面板）

- 顶栏计时徽标：没有计时器时是面板图标（`ti-layout-sidebar-right`）；有运行中的计时器时显示小时钟 + 实时用时（多个运行时前面带数量）；只剩已暂停的计时器时显示暂停图标 + 暂停数量；点击打开/关闭计时面板；
- 面板首次打开时默认只占可用宽度的 **1/5**（比原生默认的 1/2 窄很多），可拖动分隔条调整；
- 面板右上角有 **⋮ 面板菜单**（拆分 / 最大化 / 宽视图 / 锁定 / 最近访问 / 关闭，也可拖动移动面板）和 **✕ 关闭按钮**，和 Orca 原生面板一致；
- 面板分「计时 / 历史」两个 tab：计时 tab 管理所有活动计时器，历史 tab 汇总全部专注记录（见下）；
- 计时 tab 里列出所有活动计时器（进行中的排在前面）：实时用时、状态（进行中显示「本段开始于 HH:mm」，已暂停显示「暂停于 HH:mm」）、已暂停总时长，以及开始时填的意图；
- 每个计时器支持：暂停 / 继续、**插入专注备注**（按当前时间写一条中间记录）、结束（弹总结）、跳到源块、丢弃（不写日志）；
- 面板头部按钮可一键暂停全部（有运行中的计时器时，逐个写默认暂停记录、不弹窗），或打开今天的日记。

### 结束与日志

- 结束时弹窗可填总结，填的内容就是记录正文；留空则正文自动放目标块的引用；
- 专注过程中可以随时「插入专注备注」：按当前时间写一条中间记录（不带起止时间，标签上只有目标和专注ID）；
- 开始/结束/中间记录默认直接追加到今天日记的末尾；如果在设置里填了「日志块名称」，会先找今天日记里的同名/同别名块（支持 `[DailyLog|Log]` 这类写法），找不到再按仓库别名找；只有同时填了「日志分区名称」时，才会自动新建日志块；
- `#专注日志` 标签实例上记录 **开始时间 / 结束时间 / 目标 / 专注ID**（不额外增加属性）：
  - 开始条：开始时间 + 目标 + 专注ID；结束时间留空
  - 暂停条：开始时间 = 这一段的开始时间，结束时间 = 暂停时刻
  - 恢复条：开始时间 = 恢复时刻，结束时间留空
  - 中间备注：目标 + 专注ID；起止时间都留空
  - 结束条：开始时间 = 最后一小段的开始时间，结束时间 = 结束时刻
- 暂停/恢复**不改变专注ID**：一次专注的所有开始、暂停、恢复、备注、结束记录都共用同一个 ID；暂停条和恢复条不会另起一次专注。
- 目标块是一个**属性的引用块**（BlockRefs 归属标签属性），平时收在标签后面的小角标里；只有「没填内容」的记录才会在正文里内联放一个目标引用作为兜底，填了内容时正文不带引用。

### 历史汇总 / 累计

- 历史 tab 直接查询笔记里所有 `#专注日志` 记录（`get-blocks-with-tags`），按 **专注ID** 分组，不额外存一份账；
- 每次专注的开始条 / 暂停条 / 恢复条 / 中间备注 / 结束条都带同一个 `专注ID` 属性，所以能归到一次会话里；
- **单次有效专注时长 = 所有「有开始时间 + 结束时间」的记录时长之和**；暂停是这些连续段之间的空隙，`墙钟 − 有效 = 暂停时长`；
- 顶部统计：今日专注 / 全部专注 / 专注次数（今日 / 全部）；按天分组，点目标或记录可跳转；
- 进行中、暂停中的会话会标「进行中 / 暂停中」，都不计入累计；没有 ID 的旧记录单独标「旧记录」保留展示；
- 命令面板：「专注：打开专注历史」直接打开历史 tab。

### 退出自动暂停 / 撤销结束

- 关闭 Orca Note 时自动暂停所有进行中的计时器（默认开启，可在设置里关）；
- 正常退出秒级准确；异常退出最多损失一个心跳间隔（5 秒）；
- 退出时来不及写日记的暂停会在下次「恢复」或「结束」时自动补写一条暂停记录，不会丢暂停时间；
- **撤销**：结束写日志后按 `Cmd/Ctrl+Z` 可撤销日志，并自动把计时器恢复（继续计时）；结束成功的通知上也有「撤销」入口，命令面板里另有「专注：撤销上一次「结束专注」」。

## 安装

```bash
npm install
npm run build
bash scripts/install.sh   # 安装到 ~/Documents/orca/plugins/orca-focus
```

重启 Orca Note，在「设置 → 插件」启用 `orca-focus`。

## 使用

- 块小点右键 →「插件命令」→ 开始专注 / 暂停 / 继续 / **插入专注备注** / 结束 / 打开专注计时面板；
- 开始/暂停/恢复/结束/插入备注弹窗里按 Enter 直接提交（Cmd/Ctrl+Enter 也可以）；输入框不接受换行，Shift+Enter 会被吞掉、不插入软换行、也不提交；输入法候选确认时按 Enter 交给输入法，不会误提交；
- 五个弹窗的确认/取消规则一致：点确认才执行（开始计时、暂停、恢复、结束、写备注）；按 Esc、点遮罩或「取消」则什么都不做。空输入也允许，按对应记录的默认文案写日志；
- 顶栏计时徽标：打开/关闭计时面板（没有计时器时是面板图标）；
- 命令面板：
  - `专注：打开/关闭专注计时面板`
  - `专注：打开专注历史`
  - `专注：开始专注（当前块）`
  - `专注：开始 / 暂停 / 继续（当前块）`
  - `专注：插入专注备注（当前块）`
  - `专注：结束专注（当前块）`
  - `专注：撤销上一次「结束专注」`
  - `专注：清理残留的专注操作块`（异常退出留下的操作块可在命令面板清理）

## 插件设置

| 设置 | 说明 | 默认 |
| --- | --- | --- |
| 专注日志标签名 | 记录使用的标签；标签上会记录开始/结束时间、目标块与专注ID，历史面板靠它汇总。改名后旧标签记录不会被识别 | `专注日志` |
| 日志块名称（留空 = 写日记末尾） | **决定记录写进哪个块**：填块名/别名，支持 `[[DailyLog]]`、`[DailyLog|Log]` 等写法（逗号分隔多个候选）；① 先在今天日记里按文字/别名/引用目标找 → ② 再按仓库别名找。留空（或填了但都找不到）时不新建，记录直接追加到今天日记的末尾 | `（空）` |
| 日志分区名称（留空 = 不自动新建） | **只在找不到日志块、需要自动创建时生效**：按顺序在今天日记里找名称/别名匹配的分区（通常是 DailyLog、今日笔记这类 H2），把新块放它下面；都找不到就放在日记最外层。留空 = 不自动新建，记录写今天日记的末尾 | `（空）` |
| 开始后自动打开计时面板 | 开始新计时后自动打开右侧面板 | 关 |
| 退出应用时自动暂停 | 关闭 Orca Note 时暂停所有进行中的计时器，下次启动显示为已暂停；关闭后退出时保留运行状态，下次启动继续计时 | 开 |
| 暂停/恢复时弹出日志 | 暂停和恢复时各弹一个可选说明的小窗；点确认才执行并写日志（空输入写默认记录），取消则不执行、不写日志。关闭该项 = 不弹窗，暂停/恢复直接执行并写默认记录 | 开 |

## 记录格式

```
16:48 开始专注：⟦目标块⟧      #专注日志（开始时间 16:48、结束时间空、目标）        ← 开始，没输入
16:48 整理方案                #专注日志（开始时间 16:48、结束时间空、目标）        ← 开始，有输入
16:50 这个接口比想象中麻烦    #专注日志（开始时间空、结束时间空、目标）            ← 中间备注
17:05 暂停专注：⟦目标块⟧      #专注日志（开始时间 16:48、结束时间 17:05、目标）    ← 暂停，没输入
17:05 接电话                  #专注日志（开始时间 16:48、结束时间 17:05、目标）    ← 暂停，有输入
17:12 恢复专注：⟦目标块⟧      #专注日志（开始时间 17:12、结束时间空、目标）        ← 恢复，没输入
17:12 回到方案                #专注日志（开始时间 17:12、结束时间空、目标）        ← 恢复，有输入
17:40 结束专注：⟦目标块⟧      #专注日志（开始时间 17:12、结束时间 17:40、目标）    ← 结束（有效 45 分钟，暂停 7 分钟）
```

- 每条记录都是 `HH:mm` + 内容；内容 = 弹窗里填的文字；没填时用「开始专注：/暂停专注：/恢复专注：/结束专注：+ 目标引用」兜底（源块已被删除时改为「（块标题）」后缀）；
- 每条记录都带同一个 `专注ID` 文本属性（一次专注里的开始、暂停、恢复、备注、结束共用）；
- **一条带「开始时间 + 结束时间」的记录 = 一段连续专注**：开始条/恢复条只有开始时间，暂停条/结束条补上结束时间；暂停时长 = 相邻两段之间的空隙；
- 因此不需要新属性，也不用解析正文时间：历史直接对「有起止时间的记录」求和，就是有效专注时长；
- 目标块通过 `#专注日志` 标签的「目标」属性关联（RefData 引用）；中间备注的起止时间留空；
- 旧版标签上的「时长」属性会在下次写入时自动清理。

## 历史与累计规则

- 历史数据来源：查询所有带 `#专注日志` 标签的块，按 `专注ID` 分组，按天倒序展示；
- 单次时长：
  - **有效专注** = 同 ID 里所有「开始时间 + 结束时间」都有值的记录，时长求和（暂停不算）；
  - **墙钟** = 最晚结束时间 − 最早开始时间；
  - **暂停** = 墙钟 − 有效；
- 累计：所有已结束会话的有效专注时长求和；「今日专注」只统计开始时间落在今天的会话；
- 进行中 / 暂停中的会话分别标「进行中」「暂停中」，都不计入累计；
- 早期没有 `专注ID` 的记录按「旧记录」单独展示，不参与分组计时（没有起止时间）；之后再产生的新记录都会带 ID。

## 已知限制

- 插件命令出现在块小点右键菜单的「插件命令」子菜单里（Orca 对非 core 命令的统一收纳方式），不在顶层；
- 「专注中的小闹钟」是 DOM 层标记（给渲染出来的 `.orca-block` 加 class + CSS 伪元素），不写块内容；编辑器重渲染后会自动补上，极少数情况下可能有短暂闪动；
- 计时器状态是**本机**的（localStorage + 插件数据兜底，不进笔记）；只有最终记录写进笔记并随 Orca 同步；
- 多窗口打开同一仓库时，计时器状态不跨窗口同步（按单窗口场景设计）；
- 结束撤销依赖 Orca 的撤销栈：请在写日志的那个编辑器面板里按 Cmd+Z；如果已经切走了，可用通知里的「撤销」或命令面板；
- 历史 tab 每次打开/刷新会查询全仓库带 `#专注日志` 的块，记录特别多时首次加载会慢一点；
- 专注操作块是**真实的子块**：计时期间会出现在被专注块的子块列表第一行（父块折叠时看不见，镜像/查询卡片里是否显示取决于该视图是否渲染子块）；它会被计入撤销栈、随笔记同步，导出时 converter 输出为空；
- 绑定通过阻止 `core.editor.moveBlocks/deleteBlocks/mergeBlocks/copyBlocks` + 每 3 秒自检实现；`deleteSelection`、缩进等少数路径无法在命令层拦截，但被删/被移后会自动补回，最坏情况约 3 秒空窗；
- 插件被禁用时会自动清理操作块；异常退出可能留下一个「专注已结束」的操作块，可用命令 `专注：清理残留的专注操作块` 清理；
- 累计用的是**有效专注时长**（扣除暂停）；墙钟时长和暂停时长在历史卡片上悬停可见；
- 依赖 Orca Note 1.93 的插件 API（块菜单、自定义面板、标签属性）。
