# orca-focus · 虎鲸笔记「专注计时」

从**任意块**发起专注计时：右键块左侧的小点 →「插件命令」→「开始专注」。计时器集中在一个专用的侧边面板里管理；开始/结束可以顺手写一条记录到今天的日记 DailyLog 分区，并打上 `#专注日志` 标签（记录开始/结束时间，专注的目标块放在标签的「目标」属性里）。

不修改块内容、不要求预先打标签，全部走 Orca 官方插件 API。

## 功能

### 从任意块发起专注

- 块左侧小点右键 →「插件命令」→「开始专注…」（Orca 把所有插件命令统一收在这个子菜单里）；
- 开始时必定写一条记录；弹窗里可以顺手填「这次要做什么」，填的内容就是记录正文（留空则正文自动放目标块的引用，见下面的记录格式）；
- 同一时间允许多个计时器并行；
- 正在专注的块前面会显示一个**闪烁的小时钟**（纯渲染层标记，不写入笔记；该块的镜像块也会显示）；
- 计时中的块下面会自动插入一个**真实的「专注操作」子块**（不是浮层，保留正常的块小点）：显示实时用时 + 📝 插入备注 / ⏸ 暂停（已暂停时变 ▶ 继续）/ ⏹ 结束；结束或丢弃后自动删除，撤销结束会重新插回来；
- 这个操作块**绑定在源块下面**：拖不走、删不掉（会提示），被其它操作带跑后 3 秒内自动拉回源块第一个子块；复制/粘贴出来的副本会显示为「已停用」，不会控制计时器；
- 操作块是笔记里的真实块，会随笔记同步、可折叠/可撤销；导出时 converter 输出为空，不会污染文本。

### 计时面板（自定义面板）

- 顶栏 `⏱` 徽标：有计时器在跑时实时显示用时，点击打开/聚焦计时面板；
- 面板分「计时 / 历史」两个 tab：计时 tab 管理所有活动计时器，历史 tab 汇总全部专注记录（见下）；
- 计时 tab 里列出所有活动计时器：进行中 / 已暂停、实时用时、开始时间；
- 每个计时器支持：暂停 / 继续、**插入专注备注**（按当前时间写一条中间记录）、结束（弹总结）、跳到源块、丢弃（不写日志）；
- 顶栏按钮可一键暂停全部，或打开今天的日记。

### 结束与日志

- 结束时弹窗可填总结，填的内容就是记录正文；留空则正文自动放目标块的引用；
- 专注过程中可以随时「插入专注备注」：按当前时间写一条中间记录（不带起止时间，只带目标引用）；
- 开始/结束/中间记录都写入今天的日记里匹配到的 DailyLog 分区（标题写成 `[DailyLog|Log]` 这类别名引用也能识别），标题/别名都找不到时再按仓库别名找，最后才自动创建；
- `#专注日志` 标签实例上记录 **开始时间 / 结束时间 / 目标**：
  - 开始条：开始时间 + 目标；结束时间留空
  - 中间备注：只有目标；起止时间都留空
  - 结束条：开始时间 + 结束时间 + 目标
- 目标块是一个**属性的引用块**（BlockRefs 归属标签属性），平时收在标签后面的小角标里；只有「没填内容」的记录才会在正文里内联放一个目标引用作为兜底，填了内容时正文不带引用。

### 历史汇总 / 累计

- 历史 tab 直接查询笔记里所有 `#专注日志` 记录（`get-blocks-with-tags`），按 **专注ID** 分组，不额外存一份账；
- 每次专注的开始条 / 中间备注 / 结束条都带同一个 `专注ID` 属性，所以能归到一次会话里；
- 单次专注时长 = 同 ID 记录里**最早的开始时间 → 最晚的结束时间**（首尾自动算）；
- 顶部累计：今日累计 / 全部累计 / 专注次数（今日 / 全部）；按天分组，点目标或记录可跳转；
- 进行中的会话会标「进行中」（还没有结束时间，不计入累计）；没有 ID 的旧记录单独标「旧记录」保留展示；
- 命令面板：「专注：打开专注历史」直接打开历史 tab。

### 退出自动暂停 / 撤销结束

- 关闭 Orca Note 时自动暂停所有进行中的计时器（默认开启，可在设置里关）；
- 正常退出秒级准确；异常退出最多损失一个心跳间隔（5 秒）；
- **撤销**：结束写日志后按 `Cmd/Ctrl+Z` 可撤销日志，并自动把计时器恢复（继续计时）；结束成功的通知上也有「撤销」入口，命令面板里另有「专注：撤销上一次结束专注」。

## 安装

```bash
npm install
npm run build
bash scripts/install.sh   # 安装到 ~/Documents/orca/plugins/orca-focus
```

重启 Orca Note，在「设置 → 插件」启用 `orca-focus`。

## 使用

- 块小点右键 →「插件命令」→ 开始专注 / 暂停 / 继续 / **插入专注备注** / 结束 / 打开专注计时面板；
- 顶栏 `⏱` 图标：打开/聚焦计时面板；
- 命令面板：
  - `专注：打开/关闭专注计时面板`
  - `专注：打开专注历史`
  - `专注：开始专注（当前块）`
  - `专注：暂停/继续（当前块）`
  - `专注：插入专注备注（当前块）`
  - `专注：结束专注（当前块）`
  - `专注：撤销上一次「结束专注」`
  - `专注：清理残留的专注按钮块`（异常退出留下的操作块可在命令面板清理）

## 插件设置

| 设置 | 说明 | 默认 |
| --- | --- | --- |
| 专注日志标签名 | 记录使用的标签，标签上会写开始/结束时间与目标块 | `专注日志` |
| 日志块名称 | 收集专注记录的块/分区名称，支持 `[[DailyLog]]`、`[DailyLog|Log]` 等写法（逗号分隔多个候选）；先在今天的日记里找，找不到再按仓库别名找，最后自动创建 | `工作日志` |
| 日志分区名称 | 自动创建日志块时放在哪些名称/别名的 H2 下（逗号分隔） | `DailyLog,今日笔记,日志` |
| 开始后自动打开计时面板 | 开始新计时后自动打开右侧面板 | 关 |
| 退出应用时自动暂停 | 关闭 Orca Note 时暂停所有进行中的计时器 | 开 |

## 记录格式（v0.4）

```
16:48 开始专注：⟦目标块⟧         #专注日志（开始时间、结束时间（空）、目标）   ← 开始没填备注
16:48 整理方案                   #专注日志（开始时间、结束时间（空）、目标）   ← 开始填了备注
16:50 这个接口比想象中麻烦       #专注日志（开始时间（空）、结束时间（空）、目标） ← 中间备注
16:51 结束专注：⟦目标块⟧         #专注日志（开始时间、结束时间、目标）         ← 结束没填总结
16:51 写完初稿                   #专注日志（开始时间、结束时间、目标）         ← 结束填了总结
```

- 每条记录都是 `HH:mm` + 内容；内容 = 弹窗里填的文字，没填时用「开始专注：/结束专注：+ 目标引用」兜底；
- 只有一个时间戳（记录时刻），不显示时长；
- 每条记录还带一个 `专注ID` 文本属性（同一次专注的三类记录共用一个 ID），历史 tab 用它归组；
- 目标块通过 `#专注日志` 标签的「目标」属性关联（RefData 引用）；开始条/中间备注里的起止时间按上面的规则留空；
- 旧版标签上的「时长」属性会在下次写入时自动清理。

## 历史与累计规则

- 历史数据来源：查询所有带 `#专注日志` 标签的块，按 `专注ID` 分组，按天倒序展示；
- 单次时长：`同 ID 的最晚结束时间 - 最早开始时间`（墙钟时间，包含中途暂停）；
- 累计：所有有开始+结束的会话时长求和；「今日累计」只统计开始时间落在今天的会话；
- 进行中的会话显示为「进行中」，没有结束时间，因此不计入累计；
- 早期没有 `专注ID` 的记录按「旧记录」单独展示，不参与分组计时（没有起止时间）；之后再产生的新记录都会带 ID。

## 已知限制

- 插件命令出现在块小点右键菜单的「插件命令」子菜单里（Orca 对非 core 命令的统一收纳方式），不在顶层；
- 「专注中小闹钟」是 DOM 层标记（给渲染出来的 `.orca-block` 加 class + CSS 伪元素），不写块内容；编辑器重渲染后会自动补上，极少数情况下可能有短暂闪动；
- 计时器状态是**本机**的（localStorage + 插件数据兜底，不进笔记）；只有最终记录写进笔记并随 Orca 同步；
- 多窗口打开同一仓库时，计时器状态不跨窗口同步（按单窗口场景设计）；
- 结束撤销依赖 Orca 的撤销栈：请在写日志的那个编辑器面板里按 Cmd+Z；如果已经切走了，可用通知里的「撤销」或命令面板；
- 历史 tab 每次打开/刷新会查询全仓库带 `#专注日志` 的块，记录特别多时首次加载会慢一点；
- 专注操作块是**真实的子块**：计时期间会出现在被专注块的子块列表第一行（父块折叠时看不见，镜像/查询卡片里是否显示取决于该视图是否渲染子块）；它会被计入撤销栈、随笔记同步，导出时 converter 输出为空；
- 绑定通过阻止 `core.editor.moveBlocks/deleteBlocks/mergeBlocks/copyBlocks` + 每 3 秒自检实现；`deleteSelection`、缩进等少数路径无法在命令层拦截，但被删/被移后会自动补回，最坏情况约 3 秒空窗；
- 插件被禁用时会自动清理操作块；异常退出可能留下一个「专注已结束」的操作块，可用命令 `专注：清理残留的专注按钮块` 清理；
- 累计用的是墙钟时长（含暂停），不是“有效专注时长”；
- 依赖 Orca Note 1.93 的插件 API（块菜单、自定义面板、标签属性）。
